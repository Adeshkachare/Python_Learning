# Python Learning 🐍

Welcome to my **Python Learning Repository**! This repository documents my journey of learning Python, from fundamental programming concepts to advanced topics, through notes, examples, exercises, coding challenges, and projects.

My goal is to build a strong foundation in Python, improve my problem-solving skills, and develop practical programming experience.

## 📚 Course Structure

| Folder | Topics |
|---|---|
| `00_Introduction_to_Python` | Introduction, Python fundamentals, interpreter, CPython, bytecode, and execution |
| `01_Expressions` | Expressions, variables, operators, and evaluation |
| `02_Flow_Control` | Conditional statements and decision-making |
| `03_Loops` | Iteration, `for` loops, `while` loops, and loop control |
| `04_First_Project` | Practical project applying fundamental concepts |
| `05_Coding_Test_1` | Programming exercises and problem-solving practice |

| `07_Lists` | Lists, indexing, slicing, and list operations |
| `08_Other_Data_Structures` | Tuples, sets, dictionaries, and other data structures |
| `09_Second_Project` | Project applying functions and data structures |
| `10_Coding_Test_2` | Intermediate coding exercises |
| `11_Strings` | String manipulation, methods, and formatting |

| `13_Third_Project` | Practical project applying learned concepts |
